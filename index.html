03 / BEFORE YOU SUBMIT
Review the record.
  • Core fields — Number, name, stereo-complete SMILES and scientific organism name. DOI is optional; lotus curate currently handles name, SMILES, organism and DOI when provided.
  • Collection place — Choose a named Wikidata place (wd:Q…) or set an exact location (geo:lat,lon). Map pins and search queries use external services; review identities and coordinates.
  • Context fields — The remaining columns document provenance for a proposed future curation extension; they are not currently validated by lotus curate.
